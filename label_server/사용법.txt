LWIR 라벨 편집 사용법

1. 원드라이브가 동기화된 컴퓨터에서 label_editor.html 을 크롬이나 엣지로 엽니다 (더블클릭).
   원드라이브 웹사이트 안에서는 열리지 않습니다. 동기화된 폴더의 파일을 여세요.
2. [폴더 열기]를 누르고 rec_person1_20261109_140236\labels_yolo26x_bytetrack 폴더를 고릅니다.
   "편집 허용"을 물으면 허용해야 저장이 그 폴더에 바로 됩니다.
3. 고치기
   - 박스 클릭 → [이 박스 지우기] 또는 Del
   - 같은 사람인데 번호가 다르면: 박스 선택 → 번호 칸에 합칠 번호 → [바꾸기]
     ("이 프레임부터 뒤로만"을 끄면 전체 프레임에 적용)
   - 잘못된 번호 전체 삭제: [이 번호 전체 지우기]
   - 박스 이동: 가운데를 끌기 / 크기: 모서리를 끌기
   - 놓친 사람: [그리기 시작] 또는 N 키 → 드래그, 또는 C 키로 이전 프레임 박스 복사
   - 다 본 프레임은 R 키로 "확인함" 표시
   - 실수는 Ctrl+Z
4. [저장] 또는 Ctrl+S → 같은 폴더에 tracks_edited_mot.txt, review_state.json 이 생깁니다.
   원래 tracks_mot.txt 는 바뀌지 않습니다. 다음에 폴더를 열면 고친 파일부터 이어서 엽니다.

파일 형식 (tracks_edited_mot.txt): 프레임,번호,x,y,폭,높이,점수(손으로 고친 박스=1),클래스(0=사람),-1,-1
프레임 번호 1 = images/000001.png, 좌표는 640x480 기준.
라벨은 YOLO26x + ByteTrack이 자동으로 만든 후보이며 정답이 아닙니다.
