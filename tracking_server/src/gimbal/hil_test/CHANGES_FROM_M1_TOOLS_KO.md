# 장치의 시험 도구에서 바꾼 것 — 줄 목록과 이유 (2026-11-11 두 번째 판, 2026-11-12 세 번째 판)

- 원본: 장치에 있는 그대로의 `pid_hil.py`, `lead_hil.py` (이 PC의 `../m1_tools/`, 읽기만 함).
- 바꾼 줄 전체는 `pid_hil.diff`, `lead_hil.diff` 에 있다 (`-` 원본 줄, `+` 새 줄). 코드 안에서 첫 판(오늘 저녁)에 바꾼 줄에는 `v27`, **두 번째 판(안전 검토 반영 + 세 단계)에 바꾼 줄에는 `v27b`**, **세 번째 판(두 번째 안전 검토 반영)에 바꾼 줄에는 `v27c`** 표시가 있다.
- 첫 판의 파일은 `../run_before_fixes/` 에 그대로 있다. 첫 판의 계획 파일 `plan_v27.json`, `plan_v27_dry.json` 은 이 폴더에서 뺐다(그 폴더에 남아 있다). 실행 모드 `real`, `dry` 는 없어지고 `stage1~3`, `dry1~3` 이 됐다.
- 바꾸지 않은 것: 영상 이동 측정의 계산(Shift — 화면 사이 허용 폭만 값으로 뺐다), 예측 제어 계산(lead_shift 는 서버 파일에서 그대로 읽음), 끊긴 구간 다시 하기 규칙의 횟수(구간 3번, 전체 8번 — 세 번째 판에서 160 px/s 이상 걸음만 더 조였다: 0절), BASE 옵션의 순서(`--speed-max 10` 이 앞에 있고 계획의 `--speed-max 100` 이 뒤에서 덮어쓴다. 라이브 서버가 프로그램을 띄울 때와 같은 순서).
