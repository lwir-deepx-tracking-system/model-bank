# 11-16 현장 녹화 목록 (3단계 우리 카메라 자료)

왜: 3단계(우리 카메라로 다듬기)에 쓸 녹화가 부족하다. 시험 녹화와 겹치지 않는 실내 녹화가 하나뿐이었고, "보이다가 가려지는" 장면이 거의 없었다(README 7-2절).

## 준비
- 열화상 카메라 USB 를 **파란 포트**에 꽂는다(검은 포트는 원격으로 껐다 켤 수 없음).
- 장치 화면에서 실시간 영상이 나오는지 확인한 뒤 녹화한다.
- (가능하면) 컬러 카메라(웹캠이나 휴대폰)를 열화상 렌즈 **바로 옆**, 같은 방향으로 단단히 고정한다. 두 녹화를 같이 시작하고, 시작할 때 손뼉을 치거나 손을 크게 흔들어 시간을 맞출 표시를 남긴다.
- 장면마다 시작 시각과 장면 이름을 적어 둔다.
- 처음과 끝에 **사람 없는 방 10초**.

## 장면 (장면마다 1~2분, 2~4명, 사람과 옷을 바꿔 가며 2~3번)

| 장면 | 하는 것 | 왜 |
| --- | --- | --- |
| A. 들어와서 책상 뒤 | 다 보이게 걸어 들어와 책상 뒤에 앉음 → 잠시 있다가 일어나 나감. 자리 바꿔 3번 | 앞뒤 프레임으로 가려진 구간 라벨을 이어 붙일 수 있음 |
| B. 모니터 뒤 | 모니터 뒤에 앉아 머리 윗부분만 보이게 | 지금 가장 못 찾는 경우 |
| C. 카메라 가까이 | 카메라에서 0.5~1m 앞을 지나감, 몸·팔이 화면을 크게 채움 | 놓친 사람이 배경으로 들어가던 경우 |
| D. 화면 가장자리 | 왼쪽·오른쪽 끝에 반쯤 걸쳐 서 있기·지나가기 | 잘린 사람 |
| E. 숙이기 | 물건 집기, 쪼그려 앉기, 몸 숙이기 | 놓치던 자세 |
| F. 엇갈리기 | 두 사람이 서로 앞을 지나감, 한 사람이 다른 사람을 가림 | 번호 유지·가림 |
| G. 여럿 앉기 | 2~4명이 테이블에 둘러앉음 | 가까이 붙은 사람들 |
| H. 멀리 | 방·복도 끝까지 걸어감 | 작은 사람(원거리 유지) |

## 나눠 쓰기 (중요)
- 내일 녹화 중 **한두 장면(사람 다르게)은 최종 시험용**으로 따로 떼어 학습·가짜 라벨에 쓰지 않는다. 나머지는 3단계 학습용.
- 녹화가 끝나면 모델이 먼저 관절을 달고(작은 사람은 확대해서), 사람은 고치기만 한다(수백 장).
