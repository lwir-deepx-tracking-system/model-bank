# 2026-11-25 YOLO26m 관절 학습과 NPU 변환

## 학습과 평가

- COCO RGB 사전학습 → 흑백 COCO → OTP2 → LLVIP-Pose → 자체 LWIR 순서. MOT17은 원래 관절 정답이 없어 이 학습에서 제외했다. 공개 학습은 배치 16, 640 입력, AdamW, 혼합 정밀도, 시드 0, 단계별 30에폭이다.
- 흑백 COCO는 공유한다. 이후 각 단계의 마지막 또는 최고 검증 가중치를 이어 쓴다. 공개 학습의 에폭 로그와 가중치 선택용 검증은 OTP2 934장이다. LLVIP-Pose 1,139장과 자체 LWIR 207장은 이 문서의 별도 비교 평가에 사용했다.
- 자체 LWIR 네 조건은 두 경로에서 전체 또는 검출·관절 헤드만 각각 30에폭 학습했다. 배치 4, AdamW, 시작 학습률 0.00002, 혼합 정밀도, 시드 0이다. 자체 학습에는 1,253장 고유 영상 프레임을 실내·중거리·야외 각 551회로 맞춰 총 1,653회 사용했다. Val은 환경별 69장이다. 빠진 관절 좌표 일부는 E10 모델로 보완했다.
- 두 검증 데이터에 각각 253건을 평가했다. 관절 기반 박스는 정답·예측 관절 양쪽에 같은 머리~골반 계산을 적용했다.
- 흑백 COCO 원래 E29·E30은 보존했다. 누락 E01~E28은 동일 입력·코드 해시를 확인한 별도 재학습으로 채우는 중이다. OTP2 생략, RGB에서 자체 영상으로 직행, 원본 라벨 박스 두 경로는 예약 상태다. 전체 경로와 생략 경로의 우열은 아직 확인하지 않았다.

수치는 AP50–95이며 각 칸은 **관절 / 관절 기반 박스** 순서다.

| 자체 학습 조건 | 자체 LWIR Val 207장 | LLVIP-Pose Val 1,139장 |
| --- | --- | --- |
| 마지막 에폭 · 전체 E30 | 74.75% / 80.66% | 71.95% / 57.76% |
| 마지막 에폭 · 헤드만 E30 | 57.36% / 78.75% | 69.30% / 57.94% |
| 최고 에폭 · 전체 E30 | 74.64% / 80.91% | 59.12% / 51.92% |
| 최고 에폭 · 헤드만 E30 | 59.31% / 79.90% | 55.29% / 51.39% |

- 자체 Val 최고 83.35%는 마지막 경로 전체 E15이며 평가용 임시 가중치는 검증 완료 뒤 정리됐다. 남은 가중치 중 최고는 마지막 경로 전체의 best.pt, 관절 기반 박스 81.77%다.
- LLVIP Val 최고는 최고 경로 LLVIP E14, 관절 82.65%, 관절 기반 박스 70.31%다. 이 모델의 자체 Val 관절 기반 박스는 71.77%다.

## 양자화와 손실 확인

- DEEPX DX-COM을 사용한다. 전체 영상 모델은 640×480, 단일 열화상 채널을 세 채널로 복제한 0~255 입력이다. 그래프에서 255로 나눈다. 보정은 열화상 600장, EMA 방식, CPU, opt_level 1, aggressive partitioning 끔으로 맞췄다. 두 전체 ONNX의 크기는 각각 86,269,395바이트다. 보정 영상에는 검수 영상 264장과 별도 실내·야외 프레임을 사용했다. 시험·선택 녹화는 보정 자료에서 제외했다.
- 해상도와 관절 정보를 유지하려고 stride 8·16·32 각각의 박스, 사람 점수, 관절 원시 출력을 총 9개 텐서로 내보냈다. 17개 관절의 디코딩과 NMS는 기존 장치 코드와 같은 경로를 사용한다.
- 양자화 전 PyTorch와 FP32 ONNX 출력 8장을 대조했다. 모델이 내보내는 원시 박스·사람 점수·관절 헤드와 내보내기 래퍼의 최대 오차는 두 모델 모두 0이었다. ONNX 런타임과 PyTorch의 최대 절대 차이는 아래와 같다.

| 후보 | 전체 영상 FP32 최대 차이 | 관절 기반 박스 AP50–95 |
| --- | --- | --- |
| 자체 LWIR 보관 최고 | 0.000340 | 자체 LWIR 81.77% |
| LLVIP 최고 E14 | 0.000217 | LLVIP-Pose 70.31% |

- 자체 LWIR 모델은 NPU 한 장 분할용 480×384 ONNX도 만들었고 8개 입력으로 확인한 최대 절대 차이는 0.000343였다. 입력에 맞춰 reshape 상수 6개만 바꿨고 가중치 초기값 바이트는 유지했다. 분할 DXNN은 검수 영상에서 만든 528개 정해진 크롭으로 보정한다.
- 표의 AP는 PyTorch 가중치 평가값이다. **INT8 변환 뒤 AP와 8090 실제 지연은 아직 측정 전**이다. 변환으로 인한 AP 손실은 동일 데이터셋의 PyTorch·DXNN 결과를 비교해 %p로 기록한다. 장치 등록에는 DXNN 파일 해시와 입력·출력 형상 검사를 적용한다.
- 자체 LWIR 전체 영상 DXNN은 컴파일을 마쳤다. DX-COM 2.4.1-rc.1로 1,382초가 걸렸고 파일 크기는 23,661,447바이트다. 자체 분할 모델과 LLVIP 전체 모델은 컴파일 중이다.
- 변환 단계와 SHA-256은 [프로토콜·가중치·변환 기록](protocol_and_artifacts.json), 에폭별 점수는 [원본 평가 표](validation_scores.csv)에 있다.
