# LWIR 사람 검출·추적 발표 인계

정리 기준: 2026-11-17 KST. 열화상에서 **작고 멀리 있는 사람을 놓치지 않으면서, 가려졌다 돌아온 사람에게 같은 ID를 주고, DX-M1에서 제때 결과를 내는 것**이 목표였다. 이 세 가지가 함께 좋아진 결과는 아직 없다. 같은 검출을 쓴 DX-M1 개발 비교에서는 오탐과 ID 변경을 줄였지만 작은 사람 누락이 늘었다. 장치의 지연은 영상 공급 방식과 모델, 측정 구간에 따라 달랐다.

## 1. 어디를 바꿨나

`640×480 RAW16 → 8비트 영상 변환 → YOLO26 검출 → Kalman·카메라 움직임 보정(GMC)·연관 → RepVGG 외형 비교·ID 복구 → 추적 결과 발행 → 브라우저 표시/짐벌 제어`

- 검출이 없는 경우와 검출은 있지만 잘못 연결된 경우를 분리했다. 탐지 적응 실험은 추적기를 고정하고, 추적 구성 대조는 검출을 고정했다. 카메라 움직임이 큰 장면에서는 GMC로 직전 위치를 현재 화면에 맞춘다.
- 11-03 기준 R0은 YOLO26m + ByteTrack, R1은 같은 클래스 연계·광류·3프레임 확인·KeepID를 추가한 기존 구성이다. R2는 R1의 확인과 재연결을 각각 학습형 게이트와 학습형 판정기로 교체했다. 게이트는 새 트랙을 내보낼지, 재연결 판정기는 유실된 공개 ID를 새 트랙에 붙일지 결정한다. 이때 GRU 게이트는 M1의 CPU에서 NumPy로, 외형 특징은 NPU에서 계산했다. 이 실험 구성과 현재 서버의 선택 모델·BoT-SORT 구성을 구분한다.
- 공개 ID는 사용자에게 표시할 번호, raw ID는 기본 추적기의 내부 번호다. 공개 ID가 같게 표시돼도 같은 실제 사람으로 돌아왔는지는 사람 GT와 비교해야 한다. 화면에서 놓친 상자를 계속 그리는 기능도 추적 성공 수치와 분리한다.
- 8770은 박스·ID·검수 상태를 저장하는 라벨 도구, 8090은 실시간 보기와 녹화 채점 도구다. [서버 안내](../../README.md)와 [모델 목록](../models/README.md)을 참고한다. 저장소의 화면 캡처는 합성 예시다.

## 3. DX-M1 INT8 고정 검출 대조와 가림 사례

FLIR 8편·3,749프레임의 동일 M1 INT8 검출 출력에 추적 구성만 바꿨다. **구성 선택에 사용한 개발 영상**이며 독립 검증이나 신뢰구간은 없다. HOTA·IDF1·작은 사람 재현율은 0~1 비율이다.

| 구성 | FP | FN | IDSW | HOTA | IDF1 | 작은 사람 재현율 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| R0 ByteTrack | 1,466 | 4,010 | 111 | 0.5480 | 0.6567 | 0.6114 |
| R1 기존 구성 | 908 | 4,214 | 58 | 0.5642 | 0.6897 | 0.5833 |
| R1에서 게이트만 변경 | 650 | 4,514 | 44 | 0.5660 | 0.6899 | 0.5466 |
| R1에서 판정기만 변경 | 908 | 4,214 | 36 | 0.5636 | 0.6939 | 0.5833 |
| R2 두 요소 결합 | 650 | 4,514 | 31 | 0.5645 | 0.6932 | 0.5466 |

게이트만 바꾸면 R1 대비 FP **258 감소**·FN **300 증가**, 판정기만 바꾸면 FP/FN 집계는 그대로이며 IDSW **22 감소**했다. R2는 IDSW가 가장 적었고 HOTA 최고는 게이트만, IDF1 최고는 판정기만 바꾼 조건이다. 작은 사람은 높이 32px 미만·IoU 0.3 기준이다. FP는 GT와 짝지어지지 않은 출력이라 중복·라벨 누락도 섞일 수 있다. FN은 짝지어지지 않은 GT, IDSW는 GT 사람과 연결한 예측 ID가 바뀐 횟수다. IDF1은 신원 기준 정밀도와 재현율의 조화평균, HOTA는 검출과 연관을 함께 보는 점수다. 추적 점수와 검출 AP50:95는 별개다.

가림 사건은 높이 30px 이상·정해진 화면 띠·IoU 0.5 매칭으로 골랐다. R0 → R2에서 **가림 후 동일 ID 유지 9/16 → 15/16**, **겹침 후 두 사람 모두 유지 13/25 → 17/25**였다. 후보도 겹침 8건에서 번호가 바뀌거나 사람을 놓쳤다. 예시 영상은 가림 전·중·후 3컷에 정답 ID와 예측 ID를 따로 붙이고, 성공·실패를 함께 보여준다. 비공개 원본: Notion 「31 · M1 INT8 최종 후보 재측정」, 「32 · 가림·겹침 사건과 비교 영상」.

## 4. 신원 연결과 위치 예측은 다른 실험이다

- **Mamba 재연결(11-06):** 고정 검출·기본 상자 위 TMOT 개발 5편, 1,450프레임. 기존 Mamba E41의 기억/위치를 보존하고, 중복 ID 양도를 막는 소유권 규칙 및 학습된 점수 잔차 A6를 비교했다. 원래 손실의 수치 기울기와 코드 기울기가 어긋나던 문제를 고정 E41 margin + 잔차로 바꿨고, 미확인 라벨은 음성으로 학습하지 않았다. 개별 후보에서 알려진 잘못 연결은 소유권 적용 4 → A6 3이지만, 최종 공개 ID로 채점한 IDSW는 51로 같다. 174번 사건에서 보존해야 하는 ID가 양도·퇴역하면 뒤 207번의 정답 후보가 될 수 없어, 점수만 더 높이는 추가 학습은 실행하지 않았다. 비공개 원본: `lwir_relink_margin_repair_20261106_v1/RESULT_KO.md`, `remaining_errors_20261106_v1/CURRENT_HANDOFF_KO.txt`.
- **가림 위치 기억(11-16):** 위치 GRU/Mamba는 유실 중 상자 위치를 예측하는 별도 계열이다. 기존 GRU는 프로젝트 라벨 TEST 14편의 유실 상자 오차가 키의 **0.336**, Kalman이 **0.110**이었다. 경계 특징을 빼고 입력·목표 규칙을 보정한 GRU는 **0.118**까지 낮췄으나 Kalman보다 여전히 불리했고, 그 TEST의 오류를 고침에 사용했다. 새 위치 Mamba는 같은 비교의 보고값 **0.127**로 Kalman을 넘지 못했다. 반면 같은 녹화 한 편(1,069프레임, 각 두 번)의 장치 재생에서 새 GRU/Kalman IDF1은 **75.36/71.81**, IDSW는 **15/17**이었다. 한 편의 신원 점수와 14편의 상자 오차를 섞지 않는다. [장치 회차와 근거](../../HANDOFF.md#8-바뀐-것-기록-새-것이-위).
- **짐벌 복귀 가드(11-16):** 8090 로그에서 같은 공개 ID가 다시 보여도 가드가 제어 입력을 막은 사례를 확인했다. 두 트랙의 실제 사람이 같았는지는 영상·독립 라벨이 없어 미확인이다. 오프라인 후보는 합성 조건에서 참 복귀 **1→3**과 오복귀 **0→1**을 모두 만들었다. 같은 FLIR 3,749프레임에서 얻은 개발 재생 **142창**은 기준 대비 출력 ID·숨김 표시가 동일했다. 따라서 실제 복귀나 안전성 개선의 근거로 사용하지 않는다. 비공개 원본: `guard_reacquire_offline_20261116/RESULT_KO.md`, `FLIR_CACHE_COMPARISON.json`.

## 5. M1 시간: 측정 경계를 먼저 붙인다

처리량은 완료 프레임 수를 경과 시간으로 나눈 FPS, **프레임 지연**은 같은 프레임의 입력과 결과 시각의 차이, **출력 간격**은 앞뒤 결과 시각의 차이다. p50은 중앙값, p95는 표본의 약 95%가 그 값 이내인 분포 지점이다. p95를 보고할 때 개별 프레임 표본인지 1초 집계의 표본인지 명시한다. 30 fps의 기준 주기는 약 33.33 ms이다. 지연 p95가 33 ms 이하여도 최대·p99, 연속 출력 간격, 카메라 노출→브라우저 표시·짐벌 응답까지 보장하지 않는다.

| --- | --- | --- |

## 6. 11-17 검수 학습과 최신 외형 결과

- **검수와 데이터 해석:** 8770에서 YOLO26x 후보를 사람이 고쳤다. V7 학습은 최종 검수 영상 264장만 사용해 5장 정정과 증강을 적용했고, 과거·외부 프레임을 별도 학습 입력으로 추가하지 않았다. 이 264장은 자체 카메라의 테스트셋이 아니다. 660개 머리 상자는 별도 라벨이며 COCO17 학습의 목표로 들어가지 않았다. 009·018의 G6 배경 처리 전수 대조(게시 32장)에서는 018의 원거리 인체 3개 궤적이 보호 마스크와 겹쳐 5프레임에서 일부 남았고, G6가 인체를 새로 그렸다는 증거는 없었다. 11-17 공개 화면의 해당 5장 수정과 학습 이미지 갱신은 별개이며, 확인 범위 밖 프레임은 이 판정에 넣지 않는다.
- **YOLO26m-pose V7/V8:** V7은 seed 0, AdamW/cosine, batch 8, 24에폭·213 업데이트를 마쳤다. OTP2 검증 934장은 평가에만 써서 학습 프레임과 분리했지만, 새 카메라 일반화의 증거는 아니다. 보존된 평가에서는 V7 체크포인트가 사전에 정한 여러 기준을 함께 통과하지 못했다. V7 E24 DXNN은 장치 기록상 임시 사용 후보였으며 실제 카메라의 GT 정확도, 전체 추적, INT8 일치 검증은 별도다. V8 시간 연속성 6에폭, 같은 증강을 쓴 별도 V8 10에폭도 기준 미통과. 고정 PC FP32 결과의 V7 E24 → V8 증강 E01은 중복 **320→154**, 130개 학습 프레임 쌍의 중심오차 p95 **10.991→9.587 px**, 20–32px 누락 **24→12**로 줄었다. 20px 미만 누락은 **88→104**, 띠 FN은 **9,899→9,979**로 늘었고 OTP2 pose AP는 **0.7306→0.7194**로 낮아졌다. 안정성은 학습에 쓰인 쌍에서 잰 값이며, 개선된 항목만으로 채택하지 않았다.
- **RepVGG-A0 직접 적응:** 이전 증류 모델의 128차원 마지막 투영만 FP32로 학습했고 몸통은 비트 단위로 같았다. 검수 이미지 264장 중 260장·감독 가능한 672개 크롭, 8에폭·304 업데이트. 외부의 고정 기존 TMOT val 432질의 Rank-1 **89.58→89.35%**, CAMEL hold 218질의 **90.30→91.68%**로 서로 다른 방향이다. 동일 오수락률 2.44%의 동일인 수락률은 TMOT **72.45→72.45%**, CAMEL **70.18→69.72%**였다.
- **RepVGG 장치와 신원 성능:** 11-17 운영 기록에서 새 INT8 외형 모델이 선택·저장됐고, 라이브 카메라 2,242프레임 시점에 약 29.4 추적 FPS로 동작을 확인했다. M1 코어 2의 시험 크롭 64개에서 유한한 128차원 출력, FP32 대비 pair cosine 변화 p95 **0.154**를 확인했다. 고정 판정기와 보관 seq17 300프레임에서는 같은 검출·기본 추적에서 기존 INT8/새 FP32의 최종 재연결이 둘 다 **동일인 11·다른 사람 1**이며 공개 ID와 상자가 동일했다. 한 개발 비교로, 보정된 새 DXNN을 사용한 독립 실카메라의 ID 정확도를 뜻하지 않는다.

### SOLIDER 교사를 검수 264장에 맞춘 뒤 RepVGG에 증류한 비교

SOLIDER의 마지막 정규화 scale·bias만 FP32로 4에폭·152회 갱신했다. 원교사와 적응교사의 확정 쌍 코사인 변화 중앙값은 **0.001007**로 사전 기준 **0.003**에 못 미쳤다. 이 판정을 기록한 뒤 같은 교사 가중치와 고정 중심을 재사용해 별도 탐색 비교를 했다. 직접 학습 A, 고정 교사 증류 B, 적응 교사 증류 C는 같은 RepVGG 몸통·초기 투영·검수 데이터·시드별 배치와 증강으로 조건마다 **3시드 × 8에폭 × 304 업데이트**를 실행했다. B의 고정 교사는 배포된 사전학습 SOLIDER를 11월 10일 자체 실내 데이터로 먼저 튜닝한 ep3이며, 이번 264장 실험에서는 갱신하지 않았다.

| 외부 유지력 진단 | A 직접 | B 원교사 증류 | C 적응교사 증류 | 과거 증류 가중치 |
| --- | ---: | ---: | ---: | ---: |
| TMOT val Rank-1 / 432 | 386/386/386 | 386/386/386 | 386/386/386 | 361 |
| CAMEL hold Rank-1 / 218 | 200/200/200 | 201/201/200 | 201/201/201 | 191 |

세 시드 모두 사전 유지력 기준을 충족하지 못했다. CAMEL에서 C는 A보다 질의 1개씩 늘었지만 원교사 B보다 0/0/1개 차이였고, 고정 임계값의 오수락은 A와 C 모두 19건, 오거절은 A 60건에서 C 62건이었다. TMOT 오수락은 A 54/55/53건, C 54/56/55건, 오거절은 A 122건에서 C 121건이었다. 같은 방식으로 기존 직접 가중치도 386/432와 200/218을 재현했다.

신규 훈련에는 검수 264장만 사용했다. 과거 R7 TEST와 원본 7장이 겹치고 그중 6장이 이번 학습 쌍에 들어가 그 TEST는 평가에서 제외했다. TMOT·CAMEL은 이전 실험에도 쓴 평가 자료다. 이 비교에서 적응교사의 추가 이득은 확인되지 않았으며, 실제 카메라의 공개 ID와 DX-M1 성능은 별도 검증 과제로 남았다. 비공개 원본: `SOLIDER_reviewed264_KD_v2/TEACHER_RESULT.json`, `SOLIDER_reviewed264_KD_exploratory_v3/{FIXED_EVAL_RESULT,VERIFICATION}.json`.
